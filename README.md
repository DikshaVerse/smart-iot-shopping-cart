# Smart IoT Shopping Cart

An IoT-based smart shopping cart designed to automate the billing process in retail stores using RFID technology and microcontroller-based processing.

Each product is tagged with an RFID tag, and the RFID reader scans the tag when the item is placed in the cart. The system then calculates the total price automatically.

---

## Features

* RFID-based product identification
* Real-time price calculation
* Automatic bill generation
* Reduced checkout time in supermarkets

---

## Hardware Components

* Arduino UNO
* RFID Reader (RC522)
* RFID Tags
* LCD / Display Module
* Power Supply

---

## System Workflow

1. Each product contains an RFID tag.
2. The RFID reader scans the tag when the product is placed in the cart.
3. Arduino reads the tag ID.
4. The system retrieves the product price from the stored data.
5. The price is added to the running total.
6. The final bill is generated at checkout.
